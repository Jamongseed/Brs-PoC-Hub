PoC-H

PoC-H 시나리오 요약

정상 페이지(MAIN)가 서드파티 위젯(THIRDPARTY)을 로드한 상태에서, 사용자의 정상 행동(위젯 닫기)으로 발생한 DOM 변화(removedNodes)를 MutationObserver로 감지하고, 그 순간 추가 스크립트(injected.js)를 동적으로 삽입하는 체인을 데모합니다.

핵심은 “로드 직후엔 깨끗해 보이는데, 특정 DOM 변화가 트리거가 되어” cross-site payload가 메인 컨텍스트에서 실행되는 형태입니다.
  1. 서드파티 로드: MAIN이 THIRDPARTY SDK(sdk.js)를 로드
  2. 위젯 삽입: SDK가 iframe(widget.html)을 DOM에 주입
  3. 트리거: 사용자가 위젯 닫기 → 위젯 컨테이너 DOM 제거
  4. MO 감지: MAIN의 gate.js가 removedNodes를 감지
  5. 추가 삽입: 감지 직후 injected.js를 cross-site로 동적 로드
주의
  • 이 PoC는 데모 목적입니다. 실제 개인정보/민감정보를 입력하지 마세요.
  • PoC-H는 단일 이벤트보다 “연쇄 패턴”이 핵심입니다. (MO 등록 → 트리거 → cross-site script 삽입)
  • 룰셋 상태에 따라 일부 룰은 “BASE로만 기록”되거나 “조건 미스매치”로 승격이 안 될 수 있습니다. (아래 Evidence 항목 참고)
