PoC-B 시나리오 요약

페이지 로드 직후, 화면 전체를 덮는 투명 레이어를 최상단에 올려서 사용자의 클릭을 가로채고 동일 origin의 /ad로 강제 이동시키는 데모입니다.
  1. 투명 오버레이 삽입: DOMContentLoaded 직후 div#invisibleClickLayer를 DOM 최상단에 추가
  2. 캡처 단계 클릭 가로채기: click 이벤트를 { capture: true }로 먼저 수신
  3. 원래 클릭 흐름 차단: preventDefault() + stopPropagation()
  4. 강제 이동: 짧은 딜레이 후 window.location.href="/ad"
이 PoC의 이동은 안전을 위해 same-origin으로 제한됩니다
  • 실제 공격은 외부 도메인 이동/새 탭/연쇄 리다이렉트로 확장될 수 있으나, 데모에서는 /ad로만 이동합니다.
주의
  • 이 PoC는 클릭을 유도/가로채는 UI 조작 패턴을 재현합니다. 테스트는 안전한 환경에서 진행하세요.
