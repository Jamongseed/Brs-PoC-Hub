PoC-F 시나리오 요약

정상 로그인 폼(/login)과 서버는 정상인데, 브라우저 런타임에서 서드파티 SDK가 HTMLFormElement.prototype.submit / requestSubmit을 오버라이드해서 제출 직전에 폼 데이터를 외부로 동시에 유출하는 시나리오를 데모합니다. 서버 로그만 보면 정상 로그인처럼 보이지만, 브라우저 내부에서만 추가 유출이 발생하는 타입입니다.
  1. 서드파티 로드: MAIN이 THIRDPARTY SDK(sdk_submit_hook.js)를 로드
  2. 프로토타입 변조: SDK가 submit/requestSubmit을 커스텀 함수로 교체
  3. 제출 시 유출: 훅이 먼저 실행되어 sendBeacon(또는 fetch)로 /collect로 전송
  4. 정상 제출도 유지: 이후 원래 제출은 계속 진행되어 /login으로 정상 요청이 감
주의
  • 이 PoC는 데모 목적입니다. 실제 자격증명/개인정보를 입력하지 마세요.
  • 서버는 정상 처리처럼 보이기 때문에, 브라우저 런타임 탐지(Proto tamper + native submit hook + network hook) 결합이 핵심입니다.
