PoC-H-OBF

PoC-H-OBF 시나리오 요약

MAIN(메인 페이지)이 THIRDPARTY(서드파티) 위젯을 로드한 상태에서, 사용자가 위젯의 닫기 버튼을 누르는 순간(위젯 DOM 제거)을 MutationObserver가 감지해 추가 스크립트(injected.js)를 동적으로 삽입합니다.

삽입된 injected.js는 화면 배지 표시/이벤트 수집(예: 키 입력 등)을 수행하고, WebSocket(wss://...)으로 Collector(WS) 서버에 이벤트를 전송합니다.

본 PoC는 체인 자체를 난독화/은닉(Obfuscation) 형태로 구성해, 겉보기에는 정상 페이지 흐름처럼 보이지만 사용자 동작 트리거에 의해 런타임에 동적 주입이 일어나는 패턴을 재현합니다.
  1. 서드파티 로드: MAIN이 THIRDPARTY sdk.js를 로드
  2. 위젯 삽입: sdk.js가 iframe(widget.html)을 DOM에 삽입
  3. 트리거: 사용자가 위젯 닫기 버튼 클릭 → 위젯 컨테이너 DOM 제거
  4. MO 감지: MAIN의 gate.js가 DOM 제거(removedNodes)를 감지
  5. 동적 주입: THIRDPARTY의 injected.js를 동적 삽입
  6. 수집/전송: injected.js가 이벤트 수집 후 Collector(WS)로 전송
주의
  • 데모 목적입니다. 실제 계정/민감정보를 입력하지 마세요.
  • WS 기반 수집은 브라우저 UI에 드러나지 않을 수 있으므로, Collector(WS) 서버 로그로 확인하는 것이 가장 확실합니다.
  • 네트워크 탭에서 wss 연결 및 전송 프레임을 확인할 수 있습니다.
