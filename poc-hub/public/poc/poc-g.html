PoC-G

PoC-G 시나리오 요약

정상 사이트(VICTIM)가 서드파티 SDK(ATTACKER)를 로드하는 상황에서, SDK가 navigator.serviceWorker.register()를 호출해 피해 사이트 origin 컨텍스트에서 악성 Service Worker(/sw-evil.js)를 등록합니다. 이후 탭을 닫아도 SW는 남아, 동일 origin API(/api/account) 응답을 지속적으로 변조하는 persistence 체인을 데모합니다.
  1. 공급망 시작점: cross-site 스크립트 로드 (DYN_SCRIPT_INSERT)
  2. SW 등록 시도: SW_REGISTER 발생, 핵심은 initiatorCrossSite=true
  3. 등록 존재: SW_REGISTRATIONS_PRESENT (정보성 신호)
  4. 지속 활성: SW_PERSISTENCE_ACTIVE에서 controller 확보
  5. (옵션) 체인 확정: POC_G_SW_CHAIN 로직이 조건을 만족하면 HIGH 확정 이벤트
주의
  • 이 PoC는 데모 목적입니다. 실제 악성행위(피싱/탈취)를 하지 않고, 안전한 API 변조로만 재현합니다.
  • SW는 브라우저에 지속되므로, 테스트 후에는 PoC 페이지의 Reset(등록 해제) 또는 DevTools의 Application → Service Workers에서 unregister가 필요할 수 있습니다.
