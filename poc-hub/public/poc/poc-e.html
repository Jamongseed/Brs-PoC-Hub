PoC-E

PoC-E 시나리오 요약

외부 Hook 스크립트(공급망)가 XMLHttpRequest.prototype을 후킹하여, 사용자가 만든 정상 XHR 요청을 유지하면서 동일 요청을 여러 Collector로 복제(mirroring)하는 데모입니다.
  1. Hook 스크립트 로드: MAIN 페이지가 외부 xhr-hook.js를 로드합니다. (보통 main/hook origin 분리)
  2. XHR 프로토타입 후킹: Hook 스크립트가 XHR.prototype.open/send/setRequestHeader를 덮어써 요청을 가로챕니다.
  3. 요청 미러링: 원래 요청은 정상 수행하면서, 동일 요청을 c1/c2/c3 collector로 복제 전송합니다.
  4. 검증 포인트: BRS는 후킹 자체를 PROTO_TAMPER로 탐지하고, 미러링 행위는 Network 탭과 collector 로그로 교차 확인합니다.
주의
  • 이 PoC는 데모 목적입니다. 실제 민감정보를 입력/전송하지 마세요.
