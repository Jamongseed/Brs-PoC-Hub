PoC-H: Script Injection (2-stage loader)

우측하단 광고 위젯의 닫기를 누르면(서드파티 SDK가 위젯 DOM을 제거), 메인 페이지가 MutationObserver로 이를 감지하고 (thirdOrigin)/loader.js를 동적으로 삽입합니다.
로더는 payload.b64를 가져와 atob로 디코딩한 뒤 2차 페이로드를 실행합니다.

PoC 체인
  1. Third-party SDK(thirdOrigin)가 광고 위젯을 삽입
  2. 사용자: 닫기 클릭
  3. Main: MutationObserver로 위젯 DOM 제거 감지
  4. Main: loader.js를 동적 삽입(1차 로더)
  5. Loader(thirdOrigin): payload.b64 fetch → atob 디코드 → stage2 실행
  6. Payload: XMLHttpRequest.prototype(open/send) 후킹
  7. 사용자: 아래 버튼으로 XHR 발생
  8. Payload: 요청 메타를 (thirdOrigin)/mirror 로 미러링(서버 로그)

※ 위젯을 닫은 뒤 이 버튼을 누르면 XHR이 발생합니다. (후킹/미러링 확인용)

※ stage2 스크립트(#pocH_stage2)를 제거합니다. 이후 자동 재주입이 발생하면 persistence 증거입니다.
